Улучшенный русский перевод игры **ZED ZONE** и плагин **ZED ZONE Russian Fix** для BepInEx 6, который исправляет то, что нельзя исправить одним файлом перевода.

## Установка

1. Скачайте один из архивов из [Releases](../../releases):
   - `ZEDZONE_RU_vX.Y.Z_translation.zip` — только перевод;
   - `ZEDZONE_RU_vX.Y.Z_translation_UI.zip` — перевод и переработка интерфейса.

   Архивы отличаются одной строкой в `BepInEx/config/community.zedzone.ru.cfg`: `[Interface] Rework = false / true`. Её можно поменять и после установки (игру нужно перезапустить).
2. Steam → ZED ZONE → *Управление* → *Просмотреть локальные файлы*.
3. Распакуйте архив **прямо в эту папку** (рядом с `ZEDZONE.exe`), заменяя файлы.
4. Запустите игру. Первый запуск дольше обычного (1–3 минуты): BepInEx готовит файлы.
5. В настройках выберите язык **«Русский (by ReYndn)»**.

Если хотите без плагинов, то скопируйте только один файл из архива:
`ZEDZONE_Data/StreamingAssets/Localization/Localization_en_to_ru-RU-x-community.csv`.
Но тогда постройки и руководство останутся на английском (см. ниже).

## Удаление

Удалите `winhttp.dll` (отключает BepInEx) или папку `BepInEx/plugins/ZedZoneRU`. Чтобы вернуть файлы игры: Steam → *Свойства* → *Установленные файлы* → *Проверить целостность*.
